## Why

More and more software is built by engineers working with agents, and that's how Ian works
every day (Claude Code, Cursor, Grok Build, spec-driven development). The identity borrows
the look of an agent session on a terminal base: a prompt, tool calls, plans with steps
checked off, all in electric cyan with mono headings and sans body text. The old profile
looked like every other badge list. This one should be recognizable on the site, in
Storybook and on the GitHub profile.

## Looks like

- The same palette, type and shapes on every page and in every component.
- Agent-session touches (prompt and cursor, tool-call blocks, plan checklists, section
  rules, terminal windows) that add character without making the site harder to read.

## Not this

- A chatbot gimmick, or anything that pretends a live model is answering when it isn't.
- A fake shell you have to type into, or mono body text.
- One-off colors or sizes that bypass the tokens.
