## Why

Ian's day job is TypeScript, StencilJS and Storybook, built spec-first with coding agents.
A public token pipeline and component library, plus the spec graph the site was built from,
show that work better than any list of technologies.

## Looks like

- A public Storybook with foundations, every component in every state, and docs
  generated from source.
- Components that work in plain HTML, with typed, documented APIs.
- A "How this site was built" page that shows the intents, journeys and behaviors behind it.
- Quality you can check: accessibility tests, contrast ratios, budgets in CI.

## Not this

- A component library bigger than the site needs. Every component earns its place by
  being used on a real page.
