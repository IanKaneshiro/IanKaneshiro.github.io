## Why

Recruiters and engineers increasingly ask an AI assistant about a candidate instead of
reading the site themselves. An agentic engineer's site should give those agents clean,
accurate, structured answers.

## Looks like

- /llms.txt pointing agents to the important pages.
- A Markdown version of every page, generated from the same content.
- Structured data for Ian and the featured projects.

## Not this

- Hidden text or instructions aimed at AI. Agents read exactly what people see.
- Content written for agents that drifts from the page.
